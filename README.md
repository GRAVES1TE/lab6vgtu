# Лабораторная работа 6. Реализация разветвляющихся алгоритмов

## Описание файлов работы

В данной работе представлены решения задач на использование условных операторов (`if-else`) и тернарной операции в языке C.

### 1. `1.c` — Определение високосного года (Задача 1)
Программа определяет, является ли введенный пользователем год високосным.
- **Условие високосного года:** год кратен 4 и не кратен 100, либо кратен 400:
  ```c
  (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
  ```
- **Формат вывода:**
  - `год <число> високосный`
  - `год <число> не високосный`
- **Примеры работы:**
  - Ввод `2018` $\to$ `год 2018 не високосный`
  - Ввод `1900` $\to$ `год 1900 не високосный`
  - Ввод `2020` $\to$ `год 2020 високосный`

### 2. `2.c` — Вычисление кусочно-заданной функции (Задача 2, Вариант 5)
Программа вычисляет значение функции $F(x)$ с выводом результата через тернарную операцию внутри функции `printf`:
$$F(x) = \begin{cases} -3x + 9, & x \le 7 \\ \frac{1}{x - 7}, & x > 7 \end{cases}$$

- **Контрольные примеры:**
  | $x$ | Условие | Расчет | $F(x)$ |
  | :--- | :--- | :--- | :--- |
  | $0$ | $x \le 7$ | $-3 \cdot 0 + 9$ | $9$ |
  | $7$ | $x \le 7$ | $-3 \cdot 7 + 9$ | $-12$ |
  | $-2$ | $x \le 7$ | $-3 \cdot (-2) + 9$ | $15$ |
  | $8$ | $x > 7$ | $1 / (8 - 7)$ | $1$ |
  | $11$ | $x > 7$ | $1 / (11 - 7)$ | $0.25$ |
  | $7.5$ | $x > 7$ | $1 / (7.5 - 7)$ | $2.0$ |

### 3. `3.c` — Расстояние до полудня или полуночи (Задача 3, Вариант 21)
Программа принимает время в часах (0–24) и минутах (0–60) и вычисляет, что ближе — полдень (12:00) или полночь (00:00 / 24:00), а также время в минутах до этого момента.
- Выполняется валидация входных данных: диапазон часов $[0, 24]$, диапазон минут $[0, 60]$.
- Перевод в общее количество минут от начала суток: `total = hours * 60 + minutes` (с нормализацией при 24:00).
- Вычисление расстояния:
  - До полуночи: $\min(\text{total}, 1440 - \text{total})$
  - До полудня: $|\text{total} - 720|$
- При равенстве расстояний (в 06:00 и 18:00) выводится сообщение об одинаковом времени до обоих событий.

### 4. `dz6.c` — Принадлежность точки заштрихованной области (Домашнее задание 6, Вариант 21)
Программа проверяет, принадлежит ли точка с координатами $(x, y)$ закрашенной треугольной области.
- **Вершины треугольника:** $A(3, 5)$, $B(3, -5)$, $C(7, 0)$.
- **Граничные прямые:**
  1. Вертикальная граница: $x = 3$
  2. Верхняя наклонная граница $AC$: $y = -1.25x + 8.75$
  3. Нижняя наклонная граница $BC$: $y = 1.25x - 8.75$
- **Система условий:**
  ```c
  x >= 3.0 && x <= 7.0 && y <= (-1.25 * x + 8.75) && y >= (1.25 * x - 8.75)
  ```
  *(или симметричная форма: `x >= 3.0 && x <= 7.0 && fabs(y) <= 1.25 * (7.0 - x)`)*
- **Контрольные точки:**
  - $(4, 0)$ — внутри области (принадлежит)
  - $(5, 1)$ — внутри области (принадлежит)
  - $(3, 5)$ — вершина треугольника (принадлежит)
  - $(7, 0)$ — вершина треугольника (принадлежит)
  - $(2, 0)$ — вне области ($x < 3$)
  - $(8, 0)$ — вне области ($x > 7$)
  - $(4, 4)$ — вне области ($y$ выше границы)
